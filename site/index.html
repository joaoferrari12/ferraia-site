A ideiaThe idea

A mesma tela. Outro negócio. Same screen. Different business.

As etapas do quadro, o que se anota sobre cada atendimento, os cargos, as formas de pagamento e as mesas são dados que o dono define. Nenhuma linha de código muda entre uma pizzaria e um pet shop. Board stages, what gets recorded per job, roles, payment methods and tables are data the owner defines. Not a single line of code changes between a pizzeria and a pet shop.

Quem opera não precisa entender o sistema. O sistema é que precisa entender o negócio. The people running the place don't have to understand the system. The system has to understand the business.

Como é feitoHow it's built

Uma pessoa, agentes de IA, e tudo escrito. One person, AI agents, and everything written down.

O Ferra é construído por um engenheiro, com o Claude Code como método de engenharia e não como autocompletar: cada decisão vira um registro, guardas automáticas recusam publicar quando uma regra quebra, e baterias de teste andam o dia inteiro de negócios fictícios anotando o que está certo e o que está errado. Ferra is built by one engineer, using Claude Code as an engineering method rather than autocomplete: every decision becomes a written record, scripted guards refuse to deploy when a rule breaks, and test batteries walk a full day of fictional businesses, logging what's right and what's wrong.

O que rodaWhat runs it

Aplicativo instalável (PWA) que abre sem rede e carrega cada tela sob demanda, pensado para o celular barato na internet do balcão. Banco Postgres com isolamento por empresa no próprio banco, não na tela. Funções de borda para o que o navegador não pode fazer. Publicado na borda da Cloudflare.An installable PWA that opens offline and loads each screen on demand, designed for a cheap phone on the shop's Wi-Fi. Postgres with per-company isolation enforced in the database, not in the UI. Edge functions for what the browser can't do. Served from Cloudflare's edge.

O método, abertoThe method, in the open

O jeito de construir o Ferra está publicado como um pacote de skills do Claude Code: guardas que recusam, baterias que registram certo e errado, vereditos medidos no git.
